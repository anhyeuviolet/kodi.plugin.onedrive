<objective>
Establish the two facts this phase cannot establish for itself: that the repository is its own
project rather than a node in the upstream fork network, and that a test environment exists in
which a clean-profile result means something.

Purpose: SETUP-06 is not paperwork. Eight hardcoded add-on-id lookups in the module being
vendored keep resolving on any machine where a sibling cloud-drive add-on is installed, so the
whole de-hardcoding pass looks correct on a contaminated profile and fails only for users. The
clean profile is the instrument, not the ceremony. ID-05 is here rather than later because it is
a lead-time item with no code dependency.

Output: A recorded environment inventory, a detached repository with its history intact, and
kodi-addon-checker installed on the development machine.
</objective>
